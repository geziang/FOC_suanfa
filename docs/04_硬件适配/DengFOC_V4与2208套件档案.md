### 3.1 参数来源优先级（2026-09-17 立为项目规则，与 SPEC-T §1 同源）

**① 官方标称（本表 §2）→ ② 辨识数据（本平台仅交叉验证与未知量收口）→ ③ 反推估算（须标注来源与适用范围）。**

理由：本项目非高精度系统；辨识设备精度受限，结果可能反不如厂家标称；辨识方法论已在实验室底层双环系统完整验证（能力已证明，不必在套件上重复）。故本平台一律**标称优先，忽略批次/型号差异**。当前 ③ 类参数仅转动惯量 J ≈ 1.05e-5 kg·m²（官方速度环基线在 ωv=20 rad/s 下反推，示例 05 计算区），P3 辨识收口。

## 4. 上电与安全注意

1. **上电仪式**：任何 `driver.init()` 之前必须 `dengfoc_v4::earlyInit()`——相线输入上拉 + 12bit ADC（官方例程同款，库内已内置到示例 setup）；
2. **供电**：12V 额定；串口会阻塞等待电压 ≥11.1V 才继续初始化（官方流程同款）；
3. **开环警告**：官方对开环模式 `voltage_limit=2V` 有强烈警告（长时间过大电压电流可能烧板），本库闭环限压 = 0.5A × 8.25Ω ≈ **4.1V**，进一步放宽须有数据支撑；
4. **使能共用**：使能脚 12 双路共用，双电机切换控制时注意两路桥臂状态（MotorManager 切换时自动失能旧电机）；
5. **首次标定**：initFOC 标定时电机会有小幅转动，保持转子自由。
