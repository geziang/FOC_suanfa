## 2. 口径声明：主口径为什么是"法A · 低中频窗"

1. **τf 的信息在低速时间占比**（EXP-09 课题一）：速度轨迹充分扫过低速区的频段（f≲5Hz，每半周期 0→±21→0 rad/s 完整过零）内 τf 可辨识；高频段速度幅值被黏滞钳位在 A/b≈21 rad/s、几乎不过零停留，τf 无信息。run2 分窗实证：低频窗 τf=1.14e-3±0.78e-3、中频窗 1.18e-3±0.39e-3（两窗独立互含），高频窗 0.12e-3±0.53e-3（无信息）；
2. **全窗 LSQ 会被无信息段劫持**（EXP-09 课题二）：高频段强 b·Δθ 杠杆把 b 拉高至 1.9e-4、τf 挤为零（run2 全窗法A τf≈5e-7±6e-6 塌）——全窗拟合不是分窗结论的平均，故主口径取窗；
3. 法B（微分法）为对照口径：θ̈=d(θ̇)/dt 一次差分对 sv 低通滤波残余敏感，J 系统性偏低（−16±1%，三 run 极稳），其价值在交叉验证而非主判据。

## 3. 双法自洽判据处置（口径注记收口）

判据设计意图是抓**未知**偏差。实测 32~34% 的分歧已被完全解构：

| 证据 | 数值 |
| --- | --- |
| 法A J 的 run 间复现 | run2/run4 相差 **0.2%**（系统性 +24.5%） |
| 法B J 的 run 间复现 | 三 run **−16±1%** |
| 两偏差方向 | 相反（法A 段端点 θ̇ 量化噪声 → J 偏大；法B LPF 残余相位滞后 → θ̈ 低估 → J 偏小） |
| 先验 4.06e-6 位置 | 恰在两法之间（3.4~5.1e-6 带中央） |

结论：分歧是两估计器**已知的、方向相反的、run 间稳定**的方法学偏差，真值被夹逼收窄——证据强度高于 20% 数值自洽的原始意图。按口径注记收口，不挂账、不改判据数值（若未来修订法A/B 算法消除系统偏差，可复跑本数据重判——四份 CSV 已入库可复算）。

## 5. 新知识入账（辨识战役的副产品）

- **b 频变边界**：法A 低速窗 b≈1.0~1.1e-4 vs 全窗 1.9e-4——单一线性 b 在全速域是近似（涡流损耗随速度超线性），"参数是模型在指定速度域内的等效值"这一边界知识入账；
- **τf 动态值 > 静态先验的物理疑点**：法A 三窗中心 1.2~1.3 mN·m，一致高于 EXP-05 静态卡死先验 0.9 mN·m 约 +40%——与 Stribeck（动摩擦<静摩擦）直觉相反，更可能是 τf↔b 分割在低速端未完全解耦的痕迹（法B 给 0.4e-3 支持此解读）；留痕不裁决，换载具/加低速专项激励（tq 偏置+小幅扫频）时可再启；
- **τf↔b 耦合的等价解现象**：不同窗/不同估计器给出的 (τf,b) 分割不同，但在中等速度域总阻性力矩上等价——参数分割的本质是"模型族内插"，不是唯一定位。
