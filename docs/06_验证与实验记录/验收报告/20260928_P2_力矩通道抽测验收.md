## 2. 口径声明（首验定档注记，REF-15 §5 预告项）

本报告 iq 实测来自固件 `[FC DBG]` 探针的 `state_.iq = Uq/R` 回读（SimpleFocMotor.cpp），与账面 τ/KT 构成**恒等链**（Uq=R·τ/KT ⇒ iq=τ/KT）——因此本判据实证的是 **τ→V→Iq 指令链**的线性度/对称性/无跳变，而非真电流闭环测量。真电流交叉验证（板载电流采样 vs 账面）是**第二轮定档决策**：可选固件加实测电流探针列，或用 01 号 MT2 台复测（REF-14 §4 回填时定）。此口径与 REF-15 §5 首验口径注记一致。
