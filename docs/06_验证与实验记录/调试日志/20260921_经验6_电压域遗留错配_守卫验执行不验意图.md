## 0. 本篇只讲四条

1. **契约变更必须做消费者全量盘点**：级联迁移改的是"速度环增益=电流域"这一全局契约，却只更新了直接消费者（速度预设）——位置预设这个间接消费者被漏，与 EXP-04 的 KT 案（常数的消费者漏盘点）同手法、异案例。[B+A]
2. **守卫验证执行忠实度，不验证意图正确性**：模式指示灯比对"固件 vs 预设意图"——预设发 MT0、固件如实执行、绿灯。**意图过时时，全链绿灯是最深的坑**。[A+B]
3. **开工拦截必须写在 run-book 里**：存在于会话记忆或聊天记录中的前置检查等于没有检查（速度环收官时已两次标注"预设改级联是开工第一件事"，仍被绕过）。REF-12 §4.2 现已内置开工前置检查。[B]
4. **波形时间轴必须当次标定**：本篇两具判读坟场（"瞬移"与 ts=0.7s）都是沿用上一份捕获的采样间隔假设所致——时基要用探针节拍交叉标定，禁止继承。[A]

## 1. 病情陈述

位置环首轮测试：任意 P 值下均大幅过冲/振荡；P=4（读回确认）下全反转阶跃过冲 88%、多摆衰减振铃、终值爬行数秒——表象为"P=4 大过冲"。触发条件=点整定台「位置环」预设；速度环单独工作正常（TST-02 已冻结验收）。

## 2. 事实链

1. `位置环_电压域_多P快翻转乱象.csv`：多 P 值混测 + 目标快速翻转（0.1~0.2s 翻一次 ≪ 环路 ts），波形不可判读——激励与环路时间尺度打架。[A]
2. `位置环_电压域_P4全反转张弛振荡.csv`：单次全反转（-1.57→+1.57），过冲 +2.7 rad（88%）、等效 ζ≈0.24、两摆后 +0.13，终值爬行 ~5s 到 ess=0.006 rad；**Angle 段均速 46 rad/s 与 Vel 峰值 6.2 两条通道互斥**。P/I/D 读回=4/0/0。[A]
3. **模式指示灯实锤：位置/电压（MC2+MT0）**——整定台位置预设仍为电压域（`torque=0`）。[A]
4. 电压域机制（B 级代码事实 + C 推断）：固件注入的速度环增益是电流域（kp=0.0025 A/(rad/s)、ki=0.0254），MT0 下被解释为电压——kp 项 0.03V 形同虚设，执行机构只剩积分（0.31 V/s 充电）+ PID_velocity.limit=2.0V 钳位 → 终末飞行速度 2V÷KE(0.032)≈62 rad/s 的**张弛振荡**：卡死充压→破摩飞扑（飞扑发生在采样间隙，故 Angle"瞬移"与 Vel 低峰并存）→冲过目标→积分数秒放电反充→回摆，幅度衰减。终值爬行=积分以 0.0086 V/s 逼近的时标。[A+B+C]
5. 修复 `e0a0d93`（预设 torque=0→2）后：`位置环_P4级联_单步首审.csv` + 探针（ctrl=2 tt=2 全程）——tr≈0.5s、超调 6.4%、ess 均值 1.5707 vs 目标 1.5708、终值微抖 ±0.008；`位置环_P4级联_复现与负向对称.csv`——四过渡全过、双向 ess ±0.005 对称（电压域 0.084 不对称消失）。[A]

## 3. 初始假设与误判

- **「P=4 大过冲=线性模型失效」**：当时合理——ζ 理论在 behaved 区全对，且数据"证实"大过冲。推翻证据：模式指示灯 MT0 实锤——**被测对象根本不是设计对象**，模型从未受审。
- **「Angle 通道瞬移=传感器在爆发段撒谎」**：当时合理——46 rad/s 表观超 velocity_limit 且与 Vel 矛盾。推翻证据：以探针 500ms 节拍交叉标定，本份捕获采样间隔实为 ~1.1s（上份才是 0.1s）——1.33 rad/拍=1.2 rad/s，完全物理。**时基假设错误，非传感器问题**。
- **「ts≈0.7s」**：时基错的连带产物。修正为 ~7s（终值爬行主导——一阶 4/ωp 只适用于线性主段）。

## 4. 排查过程与转折点

- **转折点一：P/I/D 读回钉死 4/0/0**——EXP-04"写入必读回"纪律的第二次应用，把"参数写错"嫌疑清场，压力集中到模式上。
- **转折点二：模式指示灯显示 位置/电压**——失控案防线 #2 为自己的设计初衷正名：它抓的就是"直通/域错配"家族。（但也见 §8 第 2 条：它绿灯时并不代表意图正确。）
- **转折点三：用户追问"瞬移从哪看到"**——触发时基重标定与撤案。**提问本身就是验证手段**。

## 5. 根因、修复与验证

五层因果链（每层独立成立，修复须打在正确的层上）：

1. **历史层**：`torque=0` 是电压域时代的正确配置——不是写错，是**过时**；
2. **变更层**：级联迁移（`7e03967`）改了全局契约却未做消费者全量盘点——LOOPS 表三个预设共享该契约，只改了一个；
3. **验证层**：守卫逻辑="固件 vs 预设意图"一致即绿灯——预设发 MT0、固件如实执行，全链绿灯；
4. **流程层**：开工前置检查存在于会话记忆而非 REF-12 剧本，测试开跑无人拦；
5. **现象层**：在错误的对象上测出"看似正确的假象"，骗过一整轮分析，差点把正确的分离比模型送进坟场。

修复=`e0a0d93`（预设 torque=0→2 + REF-12 §4.2 剧本重写含开工前置 + .ino J 标签）；验证=TST-03 判据表（四过渡全过、双向对称）。

## 7. 假设坟场

- **「P=4 大过冲=线性模型失效」** → 指示灯 MT0 实锤 → 模型平反：plant 非设计对象，张弛振荡系电压域机制。
- **「传感器爆发段撒谎（瞬移）」** → 探针节拍重标时基 → 撤案：数据内部自洽（80 档悬案为独立案件，保留）。
- **「ts≈0.7s」** → 同上 → 修正 ~7s，爬行主导。
- **「mds=8 可疑」** → T-P1-6 证据横跨 [0,10] 区间夹逼论证 → 降级为验收条件注记（TST-03 放弃记录①）。

## 8. 方法论与迁移用法

1. **契约变更消费者全量盘点**：改任何共享语义（配置契约、常量、单位域）前，先列"谁在读它"——本手法在本项目两连庄（EXP-04 的 KT 常数、本篇的预设契约）。
2. **守卫的边界**：验证执行忠实度 ≠ 验证意图正确性。意图过时时全链绿灯——意图正确性要靠另一双眼睛（剧本前置检查、交叉验证、评审）兜底。
3. **开工拦截进 run-book**：REF-12 §4.2 现格式="前置检查 → 模式 → 增益 → 激励 → 判据 → 抄回"，检查项必须可执行（看指示灯颜色）而非提醒性（"注意级联"）。
4. **时基纪律**：波形分析的时间轴当次标定（探针节拍交叉验证），禁止沿用历史假设；两条通道互斥时先怀疑自己的标尺。
5. **三环方法论收官对照**（位置环设计并入本篇存档）：电流环=RL 一阶零极对消（1 旋钮 ωc）、速度环=二阶配平（2 旋钮 ωv/N）、位置环=一阶速度源+P（1 旋钮 ωp=ωv/5）——**复杂度守恒，级联把它搬进内环、锁进常数，外层一环比一环简单**：4 个旋钮管住整台伺服 vs 官方基线六七个数互相牵扯试凑。单旋钮≠没方法论：窗口（分离比 ωv/3~5）、预测（tr/ts/ess）、翻车点（官方 P=20=零分离比）就是方法论本体。
