> 专题：P3 系统辨识（TST-08）首采 τf 塌零与双法自洽崩坏的诊断链
> 状态：已对齐（三课均有 run2/run4 复现数据支撑；τf↔b 低速端完全解耦为留痕开放项）
> 硬件/固件：DengFOC V4 + 2208 ｜ 02 号 FocKit_force_ctrl（486235c 首交付 → d9b8231 探针自动密度防呆）｜ identFit.py 双估计器
> 一手数据：`../波形与数据/辨识_chirp*.csv` 五份（50ms 诊断两轮 + 10ms 三轮）；判读全程离线复算
> 证据可用性声明：判据级证据为 run2/run4 双 run 复现（法A 主口径 J 相差 0.2%、法B 三 run −16±1%）；单 run 数字不单独作证
> 姊妹篇：TST-08（`../验收报告/20260929_P3_系统辨识验收.md`）；EXP-04（参数第二本账/写入必读回）；EXP-06（时基纪律）

## 0. 本篇只讲几条

1. **τf 的可辨识性=低速时间占比**，不是频率高低：速度轨迹扫过低速区（b·v→0、库仑项主导）的时间越长，τf 的话语权越大。低频大摆每半周期完整过零 → τf 活；高频段速度被黏滞钳位在 A/b、不过零停留 → τf 无信息；
2. **全窗最小二乘不是分窗结论的平均，是被无信息段劫持**：高频段强 b·Δθ 杠杆会把 b 拉高、τf 挤为零。参数回归前先做分窗敏感性分析；
3. **采样密度决定估计器的生死，且以系统偏差的形式显现**：法B（微分法）的 J 在 50ms 采样下 +64%（LPF+欠采样→θ̈ 低估→J 高估），10ms 下归位 −16%——两轮 +63.8/+64.3% 的复现让"随机噪声"假设当场出局；
4. 顺带：**激励与采样密度绑死防呆**（chirp 武装自动切 10ms）比 SOP 提醒可靠——两次 50ms 废采都是"忘设探针"，人因靠设计消除。

## 1. 病情陈述

TST-08 首采（探针 50ms）：全窗拟合法A τf=8.8e-8±3.2e-6——**点估计为零且置信半宽盖过先验 3.5 倍**（回归器自白"无信息"）；法B τf 为负；双法自洽 |ΔJ|/J=83%。表面症状是"τf 测不出来、两法打架"。

## 2. 事实链

1. 50ms 两轮（run0/run1）复现：法A b=1.909/1.934e-4（1.3%）、法B J +63.8/+64.3%、τf 塌——系统性指纹全复现；
2. run1 分窗：只用前 5s（0.5~1.6Hz）τf=0.97e-3±0.55e-3（+7.4%）**活了**；5s 后（f>1.6Hz）法A 半周期段=0 直接拒拟合——50ms+min_pts=4 → 只接受 f≤2.5Hz → **方程窗只有激励前 4 秒**；
3. 修采样密度（10ms，防呆 commit d9b8231）后 run2 分窗：低频窗 τf=1.14e-3、中频窗 1.18e-3（两窗独立、互含 CI），高频窗 0.12e-3（无信息）；**全窗拟合 τf 仍塌**（被高频段劫持）；
4. 主口径=法A 低中频窗（0~12s）：run2/run4 复现 J 5.059/5.051e-6（0.2%）、τf 1.31/1.19e-3、b 0.99/1.07e-4；法B 全窗三 run J −16±1%、b 1.58e-4±0.6%。

## 3. 初始假设与误判

- **误判一（本役最大教训）**：立项推理"τf 的信息在高频短半周期段"——依据 b·Δθ ∝ 1/f² 衰减快于 τf·Δt ∝ 1/f。分窗数据推翻：高频段速度幅值**不降**（被 A/b 钳位在 ~21 rad/s），b·Δθ 只降一阶，与 τf·Δt 同阶——对比度并未改善；真正的杠杆是低速区停留时长。**半周期积分方程的量级分析必须连同速度轨迹形状一起做，不能只看 f 的幂次**；
- 误判二：首见 τf 塌零猜"b 吸收了 τf"——方向对但层次浅：不是全数据吸收，是特定频窗内耦合；分窗后低/中频窗能稳定分割 τf/b（1.2e-3 / 1.0e-4）即是反证；
- 排除项：法B +64% 曾疑为拟合器 bug——50ms 两轮精确复现 +63.8/+64.3% 排除随机性，10ms 后归位 −16% 锁定采样密度为变量。

## 4. 排查过程与转折点

转折点=**分窗拟合**（把激励按频窗切开各自回归）：它同时回答了三个问题——τf 在哪个窗有信息（低中频）、50ms 数据废在哪（f>2.5Hz 零段）、全窗塌零的机制（劫持）。工具侧离线复算（解析 CSV→identFit）让每轮上机数据当场出判读，无需上位机按钮——诊断闭环从"采→点按钮→抄数"压缩为"贴日志→出报告"。

## 5. 根因、修复与验证

- 根因一：激励设计正确但**采样密度与 τf 信息窗错配**（50ms 丢掉全部 f>2.5Hz 段）——修复：探针自动密度防呆；
- 根因二：**全窗 LSQ 的杠杆失衡**——修复：主口径取低中频窗（TST-08 §2）；
- 根因三：法B 系统偏差（LPF 残余）——不修（对照法本分），以 −16±1% 的稳定偏差入账参与夹逼。
- 验证：run2/run4 独立双 run 复现（§2.4）即判决实验。

## 7. 假设坟场

- "τf 信息在高频端"（§3 误判一）——殉葬于分窗数据；
- "加大激励幅值可救 τf"——线性系统里降/升 A 等比缩放速度幅值，τf/b 相对占比不变，非杠杆；
- "全窗拟合=最稳健"——恰恰相反，无信息段的强杠杆段会劫持解；
- "法B 差是 bug"——两轮 0.5% 级复现的系统性偏差不是随机错误。

## 8. 方法论与迁移用法

1. **多参数辨识前先做可辨识性分窗**：按"谁的话语权"把激励数据分段各自回归，窗口间参数一致=可辨识；窗口间跳变=耦合或模型结构问题。这一步比调拟合算法便宜得多；
2. **CI 是"无信息"的自白**：点估计≈0 且 CI 半宽>先验，读作"此参数在本数据中无杠杆"，不是"测得为零"；
3. **估计器偏差要 run 间复现来定性**：一次偏差可以是噪声，两次 0.5% 级复现就是系统——然后找可控变量（本役=采样密度）做单变量对照；
4. **防呆优于 SOP**：把"必须做的设置"绑进动作本身（chirp→自动 10ms），操作面归零；
5. 双估计器互为对照的正确用法：不求数值一致，求**各自偏差已知且方向相反**——夹逼真值比强行一致信息更多。
