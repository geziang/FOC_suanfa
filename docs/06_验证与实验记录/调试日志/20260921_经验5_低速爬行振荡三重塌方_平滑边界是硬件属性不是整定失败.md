## 0. 本篇只讲四条

1. **低速停-走锯齿是三重塌方的叠加**：力矩量级掉进摩擦死区、速度反馈每拍只剩 1~2 个 LSB、破摩事件（~230 rad/s² 量级）快过环路时间尺度（~1/ωv=50ms + LPF 10ms）——线性模型三前提同时失效，ζ/带宽设计无从谈起。[A 实测现象 + C 机制]
2. **N 扫描即阻尼比扫描**：级联速度环闭环分母 s²+ωv·s+N·ωv ⇒ **ζ=½√(ωv/N)、ωn=√(N·ωv)**——kp 独占阻尼轴（2ζωn=ωv）、ki 独占频率轴。N=5/10/20 对应 ζ=1.0/0.707/0.50；**PM=atan(ωx/N) 随 N 增大而降低**（理想 76°→65°→51°，计入内环 ωc=125 与 LPF 100 滞后 ≈56°→43°→~30°）——N 是花 PM 买积分速度，不是免费午餐。[B 推导，behaved 区 A 验证]
3. **实测边界：5 rad/s 停-走、10 rad/s 平滑（N=10）**——落在此前分析预测的 5~10 区间；N=5 与 N=10 低速锯齿幅值同为 0↔8~13 量级，积分提速压不动机制。[A-实测]
4. **均值跟踪≠平滑**：锯齿态下积分把均值钉在目标（3.06≈3.0、5≈5），判据必须看"贴目标带占比/卡死拍占比"，不能只看均值。[A-实测]

## 1. 病情陈述

速度环（级联 MT2+MC1）在 3 与 5 rad/s 下 Vel 呈停-走极限环：约半数时间卡死（|v|<0.5），破摩瞬间冲至 8~13 rad/s 再被按停，周期 0.5~1Hz（≪ 环路带宽 3.2Hz）。触发条件=低速；不发生条件=转速进入双位数（10 rad/s 起 ±2 纹波平滑）。

## 2. 事实链

1. N=5（当时误标 N=10，写入未生效案见 EXP-04）3 rad/s：46% 卡死 / 32% 冲刺(v>5，峰值 13.4) / 12% 贴带(2~4)，均值 3.06；卡死段 Vq 0.15~0.25V（=I·R 对账成立，静止无反电动势）。[A]
2. N=10（探针验证 I=0.0254 落地）5 rad/s：Vel 0.1~17.3、含成串卡死拍、均值≈5；同日 10 rad/s：±2 纹波、无卡死拍；10~40 全程平滑（40 档 σ≈1.3）。[A]
3. 按更正 KT=0.032 换算：卡死段 Iq≈20~30mA → 力矩 ~0.9 mN·m 仍被按住（静摩擦+齿槽井量级 [C]）；破摩加速度 α=KT·I/J 比值与旧叙事一致（J/KT 等比），量级 ~230 rad/s²（J 极小所致）。[A+C]
4. 传感器账：AS5600 12bit（1.53 mrad）× 主循环 ~1.35kHz → **每拍 1 LSB = 2.07 rad/s**；3 rad/s 目标=每拍 1.5 LSB；LPF(Tf=10ms) 后噪声底 ±0.1~0.2（静止段实测吻合，量级自洽）。[B+推算]
5. 齿槽纹波频率=机械转速×7 对极：3 rad/s→3.3Hz，**恰≈环路带宽 3.2Hz**（环路"看见"并对抗齿槽）；20 rad/s→22Hz，远出带宽被机械惯量滤除。[B 推算]
6. 理论配平（B 级推导）：被控对象=冻结电流环×KT/(Js)（纯积分器），PI 闭环分母 s²+ωv·s+N·ωv，另有 PI 零点在 -N rad/s（N=5 时零点 -5 比极点 -10 还靠内，临界阻尼阶跃亦有轻微超调——判读 σ% 别拿纯二阶表硬对）。

## 3. 初始假设与误判

- **「提 N 能治锯齿」**：当时合理——积分攒力矩速度确实随 N 翻倍，抗摩擦看似对症。实测 N=5→N=10 锯齿幅值纹丝不动 → 降级为"改善频率不改善幅值"。
- **「低速不平滑=参数没调好/阻尼没选对」**：当时合理——ζ 理论在 behaved 区全对、且 10~40 一枪收敛佐证。被三重塌方分析+边界实测否决 → 低速锯齿是摩擦/分辨率/环率的函数，不是整定失败。
- **「N 越大 PM 越高（免费午餐）」**（更早记录）：分数写反；Bode 相位与 ζ-PM 经验式双推导纠错（§0 第 2 条）。

## 4. 排查过程与转折点

- **转折点一：均值 3.06≈3.0 的发现**——排除"环路失稳"读法（失稳不会均值钉靶），指向摩擦极限环。
- **转折点二：卡死段 Vq=I·R 对账**——直接量出"按住转子的力矩"量级（~1 mN·m），死区假设落地。
- **转折点三：N=10 数据因写入未生效作废重测（EXP-04）**——机制结论反而更硬：两组 N 下锯齿同形，"N 治不了"从单例变双例。
- **理论收口**：二阶配平（kp 阻尼轴/ki 频率轴）解释了"为什么扫 N 而不动 ωv"——动 ωv 即动 kp，同时撞内环分离比（ωc/ωv）与速度 LPF 窗口，PM 掉 30°。

## 5. 根因、修复与验证

- **根因**：对象在低速退化为"死区+粘滑"非线性元，线性设计三前提同时塌方——非参数错误、非结构错误。[A 现象 + C 机制]
- **处置**：接受边界并记录（TST-02：≥10 rad/s 平滑验收通过，5~10 rad/s 为停-走区）；升级路线挂账（编码器分辨率/主循环 I2C 提速/摩擦前馈——硬件或新工作量）。
- **验证**：边界 5~10 由两组实测夹出 [A]；机制链条自洽但无直接观测 [C]。

## 7. 假设坟场

- **「提 N 治锯齿」** → 两组 N 同形 → 降级：N 只影响锯齿频率；低速平滑不在积分轴上。
- **「低速=整定失败」** → 边界实测+机制 → 换表述：低速平滑边界是硬件函数，工程收口=记录边界或升级硬件。
- **「PM=arctan(N) 递增」** → 双推导 → PM=atan(ωx/N) 递减；N=20 档若上机需盯振铃（PM≈30°）。

## 8. 方法论与迁移用法

1. **低速三问**（判低速异常先问三件事）：模型还线性吗（力矩≫摩擦？）／反馈有几个 LSB（Δθ×f_loop）？／事件快过环路吗（破摩加速度 × 环路时间常数）？三问有任一塌方，先别动 PID。
2. **均值跟踪≠平滑**：低速判据用"贴带占比/卡死拍占比"，均值只说明积分活着。
3. **锯齿是极限环不是失稳**：均值钉靶 + 周期≪带宽 = 摩擦极限环签名；失稳振荡均值会漂。
4. **边界收口姿势**：把"≥X rad/s 平滑、以下停-走"写进验收，升级路线挂账——比"调到平滑为止"诚实且省时间。
5. **带宽-阻尼两轴观**：kp=阻尼轴（2ζωn）、ki=频率轴（ωn²）——讨论"调 P 还是调 I"时先问自己在动哪根轴、付什么代价（PM）。
