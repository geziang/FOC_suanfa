## 0. 本篇只讲四条

1. **电流环阶跃标定必须堵转**——这是工业台架惯例，理由有三层：旋转引入反电动势（时变扰动）与 dq 转速耦合、传感器角度延迟被转速放大成 D 轴伪影、旋转动态混叠进波形污染判读。[A-实测 + C-推断]
2. **本项目的伪影签名**：自由旋转下 Cd ≈ +70 mA 且**不随目标方向翻号**、零电流时为零——这是 `Cd ∝ I²` 的角度延迟伪影（Cd = I·sin(ω_e·Δt)，φ∝转速∝I），堵转后塌到 ±4 mA。[A-实测判决]
3. **对称性论证法**：对"随指令变化的误差"，先问"把指令反号它会怎么变"——一切**线性**机制（偏置以外的增益误差、角度标定误差、死区平均效应）都会跟着翻号；不翻号的一定是非线性机制。这一问直接砍掉一半假设。[B-代码事实 + 推理]
4. **流率是免费的频率计**：曲线流率 × (降采样+1) = 主循环频率——13.4 行/s × 101 ≈ 1.35 kHz，不用加任何代码就修正了"主循环十几 kHz"的错误估计，而它决定了 ωc 的数字控制上限（≤loop/10）。[C-推断，数据可复算]

## 1. 病情陈述

电流环标定（foc_current 力矩模式，±0.15 A 方波阶跃，**电机自由旋转**）中：Cq 双向跟踪正常（ess ≤2%），但 **Cd 稳在 +70 mA 上下且换向不变**——D 轴目标恒 0，这个读数意味着"45% 的电流不走转矩轴"。同时 Cq 稳态纹波 ±8~10%。**堵转后**：Cd 塌到 ±4 mA（3%），纹波塌到 ±1.5~2%，ess ≤0.3%——判据全绿。

## 3. 初始假设与误判

| # | 假设 | 当时为何合理 | 否决证据 |

| H2 | 编码器零位角误差 δ → Cd=I·sinδ | 标定值 3.347 rad 有历史；δ≈25° 可凑出 70mA | **线性机制必随 I 翻号**，实测不翻 `[A]` |

## 4. 排查过程与转折点

1. **转折一（对称性检验）**：把 H1–H3 逐一过"指令反号它会翻号吗"这道筛——全翻号，实测不翻 → 线性机制全灭，只剩**非线性**候选。
2. **转折二（机制构造）**：旋转 + 角度延迟的组合天然非线性：Park 变换用的电角度"过期" φ=ω_e·Δt，测得 `Cd = I·sin(φ)`；力矩模式下稳态转速 ∝ I 方向 → φ ∝ I → **Cd ≈ k·I²，恒正**。三条实测特征（不翻号 / 零电流为零 / 随幅值超线性）一次全中。
3. **转折三（量级核算）**：Cd/|Cq|≈0.46 → φ≈27°；AS5600 默认慢滤波群延迟 ~2 ms + 1.35 kHz 循环的采样年龄 → Δt≈2.3 ms；反推所需 ω_e≈210 rad/s（机械 ~30 rad/s，0.15A 空载云台电机的合理稳态转速）——量级自洽 `[C]`。
4. **转折四（判决实验设计）**：单变量消除——**堵转把转速这个变量归零**（φ≡0），预言 Cd→0、纹波骤降；1 分钟手握电机轴完成。

## 5. 根因、修复与验证

- **根因**：力矩模式标定让电机自由旋转；旋转使传感器角度延迟（AS5600 慢滤波 + 低循环率）等效为 Park 变换的角度滞后，产生 ∝I² 的 D 轴测量伪影，并连带把旋转/混叠动态灌进波形。
- **修复**：不是改代码——**改测试条件**：电流环阶跃标定一律堵转（已并入 REF-12 §4.2 剧本的执行纪律）。
- **验证** `[A-实测]`：堵转后 Cd 从 ±70 → ±4 mA（判据 ≤5% ✅）、纹波 ±10% → ±1.5%（✅）、ess ≤0.3%（✅）、双向对称 ✅。tr/σ%/ts 因流率（75 ms/点）低于响应时间而不可分辨——用"降 ωc 至可观测档 + 降采样 10"另行量化（见 §9）。

## 7. 假设坟场

1. **电流采样偏置** → 目标 0 段 Cd≈0 直接否决 → 若零段不干净才轮到它。
2. **编码器零位角误差** → 线性机制翻号论证否决 → 注意：它仍是**翻号型** Cd 误差的合法候选，本篇只排除了"不翻号"场景。
3. **死区电压畸变（稳态直流分量）** → 翻号论证 + 波形签名不符 → 降级为"纹波的次要贡献者"，随低电流纹波观察项挂账。
4. **高带宽振荡是 Cd 主因** → 跨 ωc 不变性否决 → 降级为独立真实问题（ωc 上限由主循环频率约束）。

## 8. 方法论与迁移用法

**电流环标定堵转的三层理由（本篇立意）**：

1. **物理层**：旋转引入反电动势——它是随转速变化的扰动，且耦合进 dq 轴，被测对象不再是标定用的纯 RL 模型；
2. **测量层**：传感器角度延迟 × 转速 = Park 角度滞后 → ∝I² 的 D 轴伪影（本文核心）——伪影随电流增大而恶化，大电流标定被污染得更厉害；
3. **判读层**：旋转动态（电气频率、6 次谐波）被低速曲线流混叠成"毛刺"，污染 tr/σ%/ess 判读——堵转后纹波从 ±10% 塌到 ±1.5% 就是直接证据。

**可迁移的三条通用手法**：

- **对称性论证**：诊断"误差随指令怎么变"（翻号？线性？平方？）——一次分类砍掉一半假设空间，比逐一试参数快一个量级；
- **单变量判决实验**：找到能把嫌疑变量归零的最便宜动作（这里是"用手握住轴"），一锤定音；
- **免费观测**：数据流自身携带频率信息（流率×降采样=循环率），下结论前先把"免费的量"榨干。
