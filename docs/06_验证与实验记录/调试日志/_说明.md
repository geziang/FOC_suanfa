# 调试日志说明

## 定位

本目录是**经验/失败教训复盘材料库**（"学到了什么、下次怎么不踩坑"），不是痕迹记录/流水账。日常单次实验证据放上级目录与 `验收报告/`；只有跨轮排查、方法论沉淀才在本目录立帖。

具体经验帖的章节结构、证据等级、预测回填、假设坟场和完成定义见 [_经验日志写作规范.md](_经验日志写作规范.md)。新建经验帖前先阅读该规范。

## 命名与序列

- 命名：`YYYYMMDD_经验N_标题.md`；
- **本项目经验帖独立计数，从经验1 开始**（与实验室底层项目的经验1~14 互不混编；引用对方经验时写"底层项目经验13"以区分）；
- 整篇被取代的帖子移入 `_归档/`（待建，首次归档时补 `_归档/_说明.md`），原文保留不删除。

## 文头状态词（五选一白名单）

草稿 / 已对齐 / 滞后 / 废弃 / **OPEN（挂账：问题未闭环，禁止提前写结论）**

## 证据等级

| 等级 | 含义 |
| --- | --- |
| A | 实测且原始数据已落盘 `波形与数据/` |
| B | 当前项目源码、依赖源码、头文件或配置核查得到的代码事实 |
| C | 基于 A/B 的推断，或尚未由判决实验直接确认的解释 |
| D | 证据不足、互相冲突或仅为待验证推测 |

实测但原始数据尚未落盘时，正文写“转引实测”并注明来源，不计为 A 级；不要为了填等级把转引材料伪装成已落盘证据。

## 写作 DoD

1. 数值可溯源（回链 `波形与数据/` 或标注等级 B 转引）；
2. 预测回填：做过预测的地方，实验后回填"预测 vs 实测"；
3. 假设留痕：被证伪的假设保留在"假设坟场"，不删除；
4. 索引同步：新帖在本文件索引表登记。
