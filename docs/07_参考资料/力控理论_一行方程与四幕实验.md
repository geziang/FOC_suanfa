## 0. 怎么用这份文档

固件每次切模式都会打印 `[FC PRED]` 预测量——**那就是答案**。学习动作固定三步：

1. **遮答案手算**：拿计算器把 §2~§3 的公式按一遍（每个只有一两次乘除开方）；
2. **上机采数**：照 §5 四幕实验单操作（力控台页，探针设 10ms，CSV 导出）；
3. **对账**：实测 vs 手算落在判据容差内 → 这一幕学会；对不上 → 缺口在公式、在参数、还是在操作，按 §6 的排查法定位。

## 1. 一行方程与两条账

### 1.1 力学账（力律在算什么）

**J·θ̈ = τ_力律 + τ_摩擦 + τ_手**

电机的转子动力学只有这一行：左边是惯性，右边三个力矩赛跑。三条力律的差别只在第一项：

| 力律 | τ_力律 | 一句话 |
|---|---|---|
| raw | tq（常数） | 我说你出多少力，就出多少力 |
| pend | −G_v·sin(θ−θ₀) | 你被一个看不见的单摆拉着（**无 D 项**，09-23 实测实证，见 §3.2） |
| imp | −K·(θ−θ\*)−D·θ̇ | 你被一根弹簧+一个阻尼器拴在 θ\* 上 |

τ_摩擦 ≈ −τ_f·sign(θ̇)（库仑摩擦，9.0e-4 N·m 实测）；τ_手 是你的手指。**记住量级**：τ_f=0.9 mN·m，G_v=5 mN·m，限幅 16 mN·m——摩擦是力律的 1/5~1/3，这就是一切"手感模糊"的根源（§4）。

### 1.2 通道账（力矩怎么变成电压）

02 号固件走**电压力矩模式**，链路两级换算：

**τ → Iq = τ/K_T → V = R·Iq**

代入本机参数（K_T=0.032 N·m/A、R=8.25 Ω）：τ=5 mN·m → Iq=0.156 A → V≈1.29 V。
反过来，固件回读的 `[FC DBG] iq` 是**账面值**（=V/R 反推，SimpleFocMotor.cpp:299）——它测的是"命令"不是"实测电流"（电压力矩模式下 SimpleFOC 不刷新采样电流，Monitor 流 Cq 恒 0，09-23 实证）。账面链路对不对账，是幕1 的事。

精度来源：τ→Iq 差 K_T 标定不确定度（②四点定标值），Iq→V 是稳态近似（忽略 L·di/dt——电气时间常数 L/R=0.52 ms，远快于机械动力学 ~30 ms，近似成立）；Vq 顶格被限压 4.12 V（≈0.5 A 持续红线）钳住。判据容差 15% 主要就是给 K_T 和 R 温漂留的。

## 2. 摩擦地板与参数区间

力控的全部"反直觉"现象都能用**四个比值**解释。先用默认参数手算一遍（答案在表尾）：

| 比值 | 公式 | 物理含义 | 默认值 |
|---|---|---|---|
| 停摆角 | asin(τ_f/G_v) | pend 能停在离井多远处 | **0.181 rad（10.4°）** |
| 每半摆衰减 | 2τ_f/G_v | pend 每摆半周期掉多少振幅 | **0.36 rad** |
| 破摩死区 | τ_f/K | imp 离 θ\* 多远就"够不着"了 | **0.354 rad（20.3°）** |
| 饱和角 | T_LIM/K | imp 超过多远力矩封顶 | **6.30 rad** |

> 手算答案：asin(0.0009/0.005)=asin(0.18)；0.0018/0.005；0.0009/0.00254；0.016/0.00254。
> 对答案：固件 `[FC PRED] pend/imp` 两行。

**09-23 实测证据（全部命中）**：

| 现象 | 实测 | 理论 | 判定 |
|---|---|---|---|
| imp 停点 | 0.287 rad（τ=0.73 mN·m） | 死区内任意处，K·θ<τ_f | ✓ 0.81τ_f |
| imp 停点 | −0.172 rad（τ=0.44 mN·m） | 同上 | ✓ 0.49τ_f |

## 3. 三条律逐个讲透

### 3.1 raw 裸力矩：零力矩基线与摩擦地板

τ=tq。tq=0 时 iq/tc 死平线，θ 是纯手感轨迹——你摸到的"阻尼感"就是 τ_f+齿槽。它的用途不是手感：

- **幕1 的对账台**：τ 阶梯 → 账面 Iq/Vq 阶梯；
- **零力矩基线**：其他律的波形减去这个底噪才是律本身的输出；
- **安全兜底**：任何异常先 `mode raw`（tq=0）断力。

### 3.2 pend 虚拟摆：正弦弹簧、周期井、摩擦衰减

**τ = −G_v·sin(θ−θ₀)，无 D 项**（09-23 实证：θ=5.688、θ̇=16.4 rad/s 时 τ=+2.8 mN·m，恰为 −G_v·sinθ；若含 D 项应为 −0.6 mN·m，实测排除）。

- **周期井**：sin 周期 2π → 每一个 θ₀+2πk 都是稳定平衡点。转子被拨过整圈后就近落井（实测停 6.153≈2π）。**"摆不回 0"不是 bug，是单摆物理**；
- **小角度**：sinθ≈θ，等效刚度=G_v=5 mN·m/rad，ω₀=√(G_v/J)=35.1 rad/s（5.59 Hz，周期 179 ms）；
- **大角度软化**：ω(A)≈ω₀·(1−A²/16)。A=1.4 rad 时 ≈30.8 rad/s（4.9 Hz）——**测频率要小幅释放**（A≈0.5 rad 修正仅 1.6%，可忽略）；
- **衰减**：纯库仑摩擦，每半摆恒掉 ΔA=2τ_f/G_v=0.36 rad。从 1.4 rad 释放：1.4→1.04→0.68→0.32→停，约 3 个半摆；
- **波形长相**：τ 是 θ 的**倒影正弦**，幅值封顶 ±G_v（θ 再大也超不过）；释放后上图 θ 围井振荡两三下粘死，下图 τ 同步缩幅。

### 3.3 imp 阻抗：直线弹簧、临界阻尼、死区停车

**τ = −K·(θ−θ\*)−D·θ̇**。设计法（REF-14 §3.2）：选 ωn=√(K/J)=25 rad/s、ζ=D/(2√(KJ))=1.0 → K=2.54e-3、D=2.03e-4 反解。

- **D 项可对账**（09-23 实证）：θ=4.100、θ̇=−30.97 时 τ=−4.1 mN·m = −K·θ（−10.4）−D·θ̇（+6.3）——两项分解严丝合缝；
- **单一归位**：只认 θ\* 一个家（不周期）——远处开启会猛拽回（实测 −27 rad/s），**切 imp 前先 raw 拨回 0 附近**；
- **释放行为**：ζ=1 临界阻尼，理论不振荡；ts≈4/(ζωn)=0.16 s；但摩擦更狠——实际停在死区 ±0.354 rad 内某处（τ 停在 K·θ<τ_f 的地方顶着摩擦）；
- **波形长相**：τ 是 θ 的**倒影直线**，拐弯处叠 −D·θ̇ 尖峰；θ 单调回中、停在死区不动（与 pend 的围井振荡是图上最直观的区别）。

## 4. 手感陷阱（09-23 案例存档）

**现象**：手转三种模式，pend 和 imp 手感"都是弹簧没区别"，raw"有阻尼但能转"。

**三条原因（都可量化）**：

1. **死区都在**：pend 10.4° / imp 20.3°——中心附近两者都是"黏住的"，手感同款；
2. **小角度静态同型**：sinθ≈θ，pend 等效刚度 G_v=5.0 与 K=2.54 只差 2 倍，同一中心同一方向——手分辨不出 2×的弱弹簧；
3. **动态区别被摩擦吃掉**：设计上 pend 该振荡、imp 该不振荡，但 ΔA=0.36 rad/半摆让 pend 一次过零就粘死（实测 −1.24 释放 → 过零 → −0.13 停），"缩回去停住"和临界阻尼手感一样。

**结论（EXP 素材）**：手感=烟雾测试（能发现"完全不对"），判别=量化（释放测试数过零、读停点位置）。判据全部走 CSV 离线，不靠手。

## 5. 四幕实验单（TST-04/05 执行载体）

通用准备：力控台页连接 → 探针(ms) 填 **10** → 设置；每幕采完导 CSV（文件名记 `202609xx_P2_幕X_*.csv`）；判据容差抄自 SPEC-P §3（草案，首验后定档）。

### 幕1 堵转阶梯（T-P2-1①）

**手算先行**：τ=±2/±5/±10 mN·m → Iq=τ/K_T、V=R·Iq 填表（答案：±0.0625/±0.156/±0.3125 A；±0.52/±1.29/±2.58 V）。

| 档 | τ (mN·m) | 账面 Iq (A) | 实测 iq | 实测 Vq | 偏差% |
|---|---|---|---|---|---|
| 1 | +2 | 0.0625 | | | |
| 2 | +5 | 0.1563 | | | |
| 3 | +10 | 0.3125 | | | |
| 4~6 | −2/−5/−10 | （对称） | | | |

操作：`mode raw` → 逐档 `tq <值>` → **手按转子堵转**（EXP-03 纪律：按稳、每档 ≥3s、读稳态）→ 记 `[FC DBG]` iq/tc 与 Monitor Vq → 归零。

判据：Iq vs 账面 τ/K_T 偏差 ≤15%，双向对称 ≤10%。
**首验口径注意**：当前 iq 列=账面（V/R），本幕实证的是"τ→V→Iq 指令链"的线性度/对称性/无跳变；真电流交叉验证（电流采样 vs 账面）是定档时要决定的口径——可选：固件加电流采样探针列（第二轮范围）或用 01 号 MT2 台复测。定档时按实情回填 REF-14 §4。

### 幕2 摆频测 J（T-P2-1②③④）

**手算先行**：ω₀=√(G_v/J)=35.1 rad/s（5.59 Hz）；J 预期=G_v/ω²=4.06e-6；ΔA=0.36 rad；停摆角 0.181 rad。

操作：`mode pend` → 转子拨到**离最近的 2πk 井 0.4~0.6 rad** 处（小幅，避开软化修正）→ 松手让它自由振荡到停 → 导 CSV。

记录：① 连续过零时间差 → 周期 T_d → ω=2π/T_d；② 逐峰（谷）幅值序列 → 每半摆 ΔA；③ 停点离井距离。

判据：②频率 vs √(G_v/J) ≤15%；③ΔA≈0.36、停摆角≈0.181（±30%）；④J=G_v/ω² vs 4.06e-6 ≤15%（第二本账交叉验证 P1 定标）。

### 幕3 慢推滞回（T-P2-2①）

操作：`mode imp`（转子先在 0 附近）→ 手指**慢推**（每程 ≥5s）θ：−1.5 → +1.5 → −1.5 一个来回 → 导 CSV。

离线：以 τ 为纵轴、θ 为横轴画散点（CSV 的 tc/th 列）。

判据（草案口径）：中线斜率 vs K=2.54e-3 ±25%；滞回半宽——**注意账面口径**：tc 本身就是律输出，散点厚度来自 D·θ̇ 与 θ 的 LPF 滞后；摩擦信息看**转向处的黏滞台阶**：换向瞬间 θ 先"卡"住直到弹力差越过 2τ_f 才动，θ 台阶宽预期 2τ_f/K=0.71 rad。判据"半宽≈τ_f ±50%"按本实测口径定档回填。

### 幕4 释放振铃与保持（T-P2-2②③）

操作A（释放）：imp 下拨到 1.5 rad 松手 → CSV。记录：过零次数（ζ=1 预期 0 次，判据 ≤1）；释放到停稳的 ts（预期 ≈0.16 s，±50%，时基按 EXP-06 用 ms 列标定）；停点（预期死区 ±0.354 内，不回弹=摩擦地板注记）。

操作B（保持）：手按停在 −0.7 rad（死区外，τ≈1.8 mN·m）按住 30 s → 看 `[FC DBG]` iq 漂移。判据 <5%（无积分顶墙证据——阻抗律无 I 项，漂移只该来自 R 温漂）。

## 6. 调试训练：故意弄坏清单

每条规则：**先在纸上写预测，再按按钮，最后解释差异**。安全线：异常立即 `mode raw`。

| # | 操作 | 预测（先写） | 现象机理 |
|---|---|---|---|
| 1 | `kd 0` 后 imp 释放 | 振铃次数变多（ζ=0，只剩摩擦衰减） | 阻尼项的作用一目了然 |
| 2 | `kk -0.00254` | 失稳：θ 发散，力矩饱和 16 mN·m，持续旋转至 velocity_limit=30 rad/s 顶格 | 负刚度=不稳平衡；做完立刻回 raw |
| 3 | `gv 0.010` / `gv 0.016` | 停摆角缩到 asin(0.09)=5.2°/3.2°；ω 升到 50/63 rad/s | 刚度↑摩擦相对↓，死区缩小 |
| 4 | 探针设 180ms（≈摆周期）看 pend 释放 | 波形骗人：振荡被混叠成慢假波 | 采样定理体感课（§7） |
| 5 | `th0 1.0`（pend） | 井搬到 1.0+2πk；`tp 1.0`（imp）则家搬到 1.0 | 平衡点参数就是律的"重心" |

## 7. 采样与时基

- **时基锚点**：一切时间量用 `[FC DBG]` 的 ms 列标定（EXP-06 纪律）——CSV 的 t_s 列即由它换算，不要用上位机到达时刻；
- **分辨率账**：pend 5.59 Hz、周期 179 ms。探针 50 ms → 3.6 点/周期（量频率勉强、看形状是折线）；10 ms → 17.9 点/周期（判据推荐档）；**Nyquist 红线 89 ms**——比它大就看不见振荡，180 ms 则混叠成假慢波；
- **探针与带宽的分工**：探针只是观察窗，不影响力律（力律每拍重算，探针只决定打印）。降探针周期不改变动力学，放心加密。
