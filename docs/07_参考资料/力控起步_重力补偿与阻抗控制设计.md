## 1. 定位与边界

**力控与三环平级，不在三环上层。** 两条用例支线共享电流环地基：

```
上层（给目标，ARC-01 契约不变）
 ├─ 运动控制：目标=角度 ──→ [位置环]→[速度环]→[电流环]→ 电机   （FocKit_commissioning，01 号，已冻结·回归台）
 └─ 交互控制：目标=刚度/力矩 → [阻抗律 K,D + τ̂g] ────→ [电流环]→ 电机   （FocKit_force_ctrl，02 号，P2 载体）
```

- **为什么绕开位置/速度环**：位置环的目标是刚性（误差归零、扰动被积分器抗掉），交互控制的目标是设定的柔顺（误差×K=可预测反力）——同一枚旋钮的两端，不可能下层刚性、上层柔软；且积分器碰到外部约束会持续加力直到饱和（T-P1-6 低速 stick-slip 的"积分攒力矩对抗静摩擦"即其缩小版），交互场景必须无 I 项。
- **本期能力边界**：重力补偿前馈、关节空间 PD 型阻抗。**不含**：导纳控制（需力传感器测外力，本项目无）、惯性整形（Hogan 完整阻抗的扩展项）、外力观测器（P3 候选：τ_ext=KT·Iq−J·θ̇−f(θ̇)，J/摩擦参数已备，见 §7）。
- 力矩通道带宽受底层时间常数约束（ωc=125、主循环 ~1.35kHz），阻抗带宽守分离比（§3.2），不提底层做不到的要求。

## 2. 理论最小集

### 2.1 重力补偿：一行静力学

连杆在竖直平面内，重力对轴的力矩只随角度变：

**τg(θ) = m·g·L·sin(θ + θ₀)**（m=配重质量、L=质心到轴距离、θ=连杆与**水平**方向夹角、θ₀=安装偏置角；出处 τ=∂U/∂θ）

θ₀ 是**装配后标定一次**的量：连杆调到水平（目测/水平仪），改 θ₀ 使 τg=0 即可——编码器零位是电气标定产物，与重力方向无关，必须加这层偏置。

控制就是力矩模式（MT2+MC0）下逐拍前馈 `setTorque(τg(θ))`，无任何闭环。效果=连杆"失重"（透明关节）。与三环范式的对照：位置环保持段"速度环积分扛齿槽拉力（vq=−0.13V）"是**反馈硬扛扰动**；重力补偿是**前馈精确抵消**——不硬扛，关节才可能柔软。

**透明度地板**：无积分器后静摩擦不再被隐藏，|τ_cmd| 低于静摩擦（实测 ≈0.9 mN·m，占连续力矩 5.6%）时连杆不动。这是直驱属性不是缺陷，写进验收预期——§4 判据①的含义是"不因重力下垂"，不是"零摩擦"。

### 2.2 阻抗控制：力矩域 PD，数学与 N 扫描同款

**T = K·(θ\* − θ) − D·θ̇ + τ̂g(θ)**

物理图像：θ\* 与连杆之间的虚拟弹簧（K）+ 虚拟阻尼器（D）+ 重力前馈。它长得像位置环 PD，但意图相反：位置环把增益调到最大求跟踪，阻抗控制把 K、D 当**产品参数**定——这个关节应该多软。

闭环就是弹簧-阻尼-质量系统（总惯量 J_total）：

**J_total·s² + D·s + K = 0 ⇒ ωn = √(K/J_total)，ζ = D/(2√(K·J_total))**

与速度环级联闭环 `s²+ωv·s+N·ωv` 是同款二阶多项式——**选 K、D 就是选 ωn、ζ**，T-P1-6 建立的 ζ/ωn/带宽工具箱原样平移（含"计入底层滞后后实际阻尼打折"的预期习惯）。

- **无 I 项**：碰约束时反力=K×偏差，有界、可预测、由设计设定——交互安全性的来源；
- **D 项即阻尼**：无需另设微分校正；其负面（低速量化噪声放大）由 §3.2 的 LPF 处理。

## 3. 参数选型

### 3.1 机械台（demo 台选型规则与占位）

| 项 | 规则/公式 | 占位（实测后回填） |
|---|---|---|
| 配重·臂 m·L | **m·g·L ≲ 0.016 N·m**（=KT×0.5A 连续上限；重力满偏也不越连续区） | 【待填写：m、L 实测】 |
| 总惯量 J_total | J_motor(4.06e-6) + m·L²（+杆自重惯量）；连杆项通常压倒性盖过电机项 | 【待填写】 |
| 臂型 | 轻质硬杆（2208 力矩小，臂自重会吃掉力矩预算） | — |

量级示例（仅供手感，非定值）：15g@10cm → τg_max≈0.0147 N·m ✓；J_total≈1.5e-4 kg·m²。

### 3.2 K/D 初值（带宽法，同款分离比）

- **ωn 窗口 = [ωv/5, ωv/3] = [4, 6.7] rad/s**（对 ωv=20 的分离比；再往内隔电流环 ωc=125 约 31 倍，更远）；**起步 ωn=4、ζ=1**（临界阻尼，首次上机最稳落点，与 T-P1-7 "先保守档上机"哲学一致）。
- **K = J_total·ωn²，D = 2ζ·√(K·J_total)**。按量级示例 J_total=1.5e-4 → K≈2.4e-3 N·m/rad、D≈1.2e-3 N·m·s/rad（J_total 实测回填后复算定档）。
- **饱和校核**：θerr_max = τ_limit/K ≈ 0.016/2.4e-3 ≈ 6.7 rad——全行程无裁剪，虚拟弹簧全程线性（选型合格的附带验证点）。
- **D 项速度估计**：沿用速度环 LPF（Tf=0.01s）第一道；低速下角度差分的量化噪声是 D 项主要污染源，判读时须区分"阻尼振铃"与"量化纹波"（探针对比 θ̇ 滤波前后）。

### 3.3 安全

- 力矩限幅沿用 `DEFAULT_TORQUE_LIMIT=0.016 N·m`（commit `ffaf7fc` 按新 KT 定的安全线）；阻抗 K·θerr 与 τ̂g 之和进同一限幅；
- demo 台负载轻，电压天花板（≈125 rad/s）与电流红线（A 域 0.5A 持续）均远不可及。

## 4. 验收判据（草案，首验后定档）

判据合同在 SPEC-P §3；本节给机理依据与测法。

### T-P2-1 重力补偿 + setTorque 抽测（三合一：同台收 KT_direct）

setTorque 的 N·m↔A 换算经 KT 定标后"结构上痊愈"但从未上机验证——本条即 P2 门票。杠杆臂+电子秤同时就是定标协议（HW-DENG §3）第三步 KT_direct 的载体，一个实验台收三件事。

| # | 判据（草案） | 机理依据/测法 |
|---|---|---|
| ① | 透明性：任意角松手，5s 内下垂 <1° | 无积分器不会漂，只会被重力拉——τg 抵消后仅剩静摩擦地板内微动 |
| ② | 静态对账：θ=±90° 时实测 Iq vs 账面 τg/KT，偏差 ≤15% | KT ±6%＋电流采样＋LPF 的合理合成误差带；账面=前馈命令直读 |
| ③ | KT_direct：命令力矩 vs 秤读力×臂长，斜率偏差 ≤10%；回填比值 s=KT_direct/0.032 | s 即电流采样标定系数（顺收 0.05A I² 缩放挂账的旁证） |
| ④ | 双向对称：θ=±90° 的 Iq 绝对值差 ≤10% | 摩擦/齿槽方向性上界 |

### T-P2-2 阻抗控制

| # | 判据（草案） | 机理依据/测法 |
|---|---|---|
| ① | 力-位移特性：偏转 Δθ 的反力回归斜率 = K ±20% | 反力 τ=Iq·KT 实测 vs K·Δθ 账面；量具为电流+角度读数，首期宽限 |
| ② | 无顶墙：持续外力保持 30s，Iq 漂移 <5% | 纯 PD 无积分的可测证据——与三环积分行为正面对照 |
| ③ | 释放回归：偏转释放后过冲 <5%、振铃 ≤1 次；ts 与 4/(ζωn) 对照 ±30% | ζ=1 设计预测；ts 判读遵守 EXP-06 时基纪律（探针节拍标时轴） |
