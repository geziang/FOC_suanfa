## 1. 项目背景

实验室关节电机项目按分期推进，自研硬件研发周期长。若"等硬件到位再开发软件"，软件排期将被硬件长尾拖垮。因此确定**软件先行**策略：把完整软件栈提前开发出来，并保证硬件到位后能低成本适配。

软件先行曾走过的路：在 STM32F103 + 杜邦线 + 驱动板的粗糙平台上，底层（电机参数辨识 + 电流环/速度环）骨架已独立完成并通过运行态验收（S0~S8 标定链、Flash 双页参数固化、FOC 电流环验收四条全过），并已完整交接。结论同时也很明确：**杜邦线级别的供电与信号完整性无法支撑上层算法开发**——继续在该平台上开发力控/运控，调试噪声会淹没算法收益。

由此做出本项目的载体决策：采用 DengFOC V4 套件（ESP32-WROOM-32U + 官方 SimpleFOC 库 + AS5600 磁编码器 + 2208 云台电机）作为中间件与上层的**开发沙盒**——硬件投入最小化、算法开发全力化。最终自研硬件到位后，通过适配层替换完成组合适配调试，收敛为一套代码。

## 2. 项目定位与边界

> **一句话目标**：在 DengFOC V4 套件上，按工业开发标准先行完成关节电机的中间件（三环级联、有感/无感）与上层（力控、运控）算法栈；以分层契约为保证，使全部算法资产在实验室自研硬件到位后零重写平移。

### 2.1 本仓库做什么

- **中间件**：速度环、位置环（级联结构）、目标斜坡、滤波；预留无感入口
- **上层**：重力补偿、阻抗控制、轨迹规划、动力学辨识、多关节协同
- **支撑**：IMotor 契约接口、DengFOC V4 板级档案、NVS 标定固化、串口调参工具链

### 2.2 本仓库不做什么

- **不重复造底层**：电流环/参数辨识已由 STM32 底层项目完成并交接；本仓库通过适配层调用（P0 用 SimpleFOC 电压力矩近似内环，P4 换实验室底层）
- **不做契约外操作**：任何"绕过 IMotor 直接操作电压/PWM"的代码不允许合入
- **不因硬件粗糙降低软件规格**：文档、版本、验收链按工业要求执行

## 3. 总体架构

```
┌──────────────────────────────────────────────────────────┐
│ 上层 app        力控(阻抗/重力补偿) · 运控(轨迹) · 辨识      │
├──────────────────────────────────────────────────────────┤
│ 中间件 control  三环级联(位置←速度←力矩) · 斜坡 · 滤波       │
├──────────────────────────────────────────────────────────┤
│ 契约 core       IMotor 运动接口  ★移植边界                  │
├──────────────────────────────────────────────────────────┤
│ 适配层 adapter  SimpleFocMotor(现行) · LabCanMotor(P4)      │
├──────────────────────────────────────────────────────────┤
│ 板级/支撑       bsp(DengFOC V4) · persist(NVS) · hmi(串口) │
├──────────────────────────────────────────────────────────┤
│ 官方 SimpleFOC 库 + DengFOC V4 硬件（只调用，不修改）        │
└──────────────────────────────────────────────────────────┘
```

依赖方向只允许向下。三段软件栈与实验室全栈的映射：

| 实验室全栈 | 本仓库对应 | 状态 |
|---|---|---|
| 底层：辨识 + 电流/速度环 | STM32 项目（已交接）；套件上由 SimpleFOC 适配层承担 | 完成 / 替代运行 |
| 中间件：三环 + 有感无感 | `src/control/` 三环级联；无感 P1 预留接口 | P0 起步 |
| 上层：力控 + 运控 | `src/control/` 扩展 + app 算法区 | P2~P3 |

### 3.1 分层契约（强约束）

上层代码只允许通过 `IMotor` 接口与电机交互：

**允许**：目标指令（力矩 N·m / 速度 rad/s / 位置 rad）、状态读取（角度/速度/电流估计）、模式切换、限幅设定、标定存取、周期 `update()`。

**禁止**：直接操作相电压、PWM 占空比、d/q 轴电流、绕组时序、寄存器；在 `core/`、`control/` 及以上层级引用 `<SimpleFOC.h>`。

契约的验收方式：上层代码文件中不得出现 `#include <SimpleFOC.h>`，编译即检查。

### 3.2 移植路径

P4 实验室硬件到位 → 新增 `LabCanMotor : IMotor`（CAN 总线对接实验室底层）→ 上层与中间件一行不改 → 组合适配调试。

## 4. 阶段路线图

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **P0 套件载体**（本版） | 库骨架、IMotor 契约、DengFOC V4 BSP、NVS 固化、串口调参壳、01力矩/02速度/03位置示例 | ①三示例编译烧录通过；②01 力矩台阶响应方向正确；③02 稳态速度误差 ≤5%（空载）；④标定参数断电重启自动注入（免二次标定）；⑤上层文件零 SimpleFOC 依赖 |
| **P1 中间件完备** | 三环级联整定方法论、目标斜坡、速度估计滤波对比、无感(SMO/PLL)接口预留、R/L/KT 辨识收口 | 级联位置环阶跃超调可整定；斜坡跟踪误差达标；歧义参数表（§6.3）全部闭环 |
| **P2 上层·力控** | 重力补偿、阻抗控制（力矩通道带宽受底层电流环时间常数约束，不提底层做不到的要求） | 阻抗参数可整定、接触稳定 |
| **P3 辨识与多关节** | 惯量/摩擦辨识（STM32 方法论迁移）、CAN 多关节 | 辨识参数交叉验证 |
| **P4 组合适配** | LabCanMotor 适配器、实验室硬件联调 | 上层算法零改动切换平台 |

## 5. 工业开发规范

1. **版本管理**：git；一次提交一件事。参考资料（`v4/`，含视频与安装包）不入库。
2. **文档编号**：`docs/` 顺序编号（00 总体方案、01 移植指南…）；验收记录按日期命名，沿用实验室 `20260913_xxx验收.md` 习惯。
3. **参数纪律**：凡进入代码的物理参数必须注明来源（规格书 / 辨识 / 官方例程），禁止拍脑袋；R/L/KT 歧义项必须在 P1 前辨识收口（见 §6.3）。
4. **单位**：全库 SI（rad、rad/s、N·m、A、V），接口边界单位见 §7。
5. **防御**：目标限幅在 IMotor 实现内强制执行；母线欠压 11.1V 自动失使能（对齐官方保护行为）。

## 6. 硬件档案

### 6.1 DengFOC V4 板级真值

来源：`v4/2、ESP有感FOC历程资料/Simplefoc库例程/` 第 1/3/8 号例程（测试库 SimpleFOC 2.2.1）。**换板只改 `src/bsp/DengFocBoard.h`。**

| 资源 | 参数 |
|---|---|
| 主控 | ESP32-WROOM-32U（板载双路三相半桥） |
| M0 相线 | A=32，B=33，C=25 |
| M1 相线 | A=26，B=27，C=14 |
| 驱动使能 | 12（双路共用） |
| M0 编码器 I2C | `TwoWire(0)`，SDA=19，SCL=18 |
| M1 编码器 I2C | `TwoWire(1)`，SDA=23，SCL=5 |
| 双编码器说明 | AS5600 地址固定 0x36，双编码器**必须**走两路独立总线 |
| VIN 检测 | 引脚 13，`analogReadMilliVolts(13) × 8.5 / 1000` |
| 欠压阈值 | 11.1 V（欠压失使能，恢复后自动回使能） |

### 6.2 2208 云台电机（规格书）

| 参数 | 值 |
|---|---|
| 槽极数 | 12N14P，**极对数 7**（官方例程 `BLDCMotor(7)` 一致） |
| 绕线电阻 | 21.2 Ω（"绕线电阻"，星形接法） |
| 相电感 | 5.3 mH |
| KV 值 | 110 KV |
| 扭矩 | 约 0.03 N·m（300 g·cm） |
| 额定/最大电流 | 0.8 A / 4.5 A |
| 适用电压 | DC 7.4~16 V，额定 12 V |
| 编码器 | AS5600，12 bit，0.087°，I2C（默认），3.3V |

### 6.3 参数歧义登记（P1 辨识收口）

| 参数 | 规格书值 | 歧义 | 当前默认（bsp） |
|---|---|---|---|
| 相电阻 | 21.2 Ω "绕线电阻" | 线间还是相电阻 | 10.6 Ω（按星形线间/2 解读；若实测 21.2 即相阻，改回 21.2） |
| 相电感 | 5.3 mH | 同上 | 2.65 mH |
| 力矩常数 KT | 0.03 N·m | 对应额定还是峰值电流；KV 换算约 0.012~0.02 | 0.03 N·m/A |

## 7. 术语与符号约定

| 量 | 单位 | 约定 |
|---|---|---|
| angle | rad | 机械角，多圈连续；零位 = init 标定零位 |
| velocity | rad/s | 低通滤波后（Tf = 0.01 s，对齐官方） |
| torque 目标 | N·m | 正值 = 使角度增大的方向 |
| iq | A | P0 为指令值/估算（U/R 稳态近似）；接入电流采样后为测量值，接口不变 |
| Idle 模式 | — | 保持使能、零电压输出（电机可被手动旋动） |
| disable | — | 桥臂高阻失能（硬断） |
| 限幅 | — | `IMotor` 实现内强制钳位，上层无需重复防御 |
